# HR Analytics Dashboard Project

## Project Overview

This HR Analytics project focuses on analyzing employee attrition data to understand why employees are leaving the organization and which employee groups are most affected. The project was created using **Excel, Power BI, Tableau, and SQL** to clean, analyze, validate, and visualize HR data.

The main objective of this project is to help HR teams identify key attrition patterns based on department, gender, age group, education field, job role, marital status, and job satisfaction.

---

## Tools Used

- Microsoft Excel
- Power BI
- Tableau
- SQL

---

## Business Problem

Employee attrition is a major challenge for every organization because it directly impacts productivity, hiring cost, employee morale, and business continuity.

HR teams need to understand:

- Which department has the highest attrition?
- Which age group is leaving the company the most?
- Is attrition higher among male or female employees?
- Which education field has more attrition?
- How does job satisfaction vary across job roles?
- What actions can reduce employee turnover?

This project answers these questions using dashboards and SQL analysis.
